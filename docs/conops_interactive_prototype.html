Anti-Loop & Anti-Deadlock Concurrency Protocol

        

          How ScriptEditor guarantees seamless bi-directional synchronization between Canvas, JSON, and C# code without circular event deadlocks.
        


        

          

            
1. Origin Tagging

            

              Every mutation is tagged with an Origin (ActivityPicker, NodeDrawer, Canvas, CodeEditor). Triggers carry this origin token.
            

          


          

            
2. Echo Suppression

            

              When a component receives a state update, it checks origin == self.id. If it originated the change, it drops the broadcast to prevent ping-pong echoing.
            

          


          

            
3. Version Stamping

            

              Each JSON mutation increments a monotonic versionId. Out-of-order or stale parse events are rejected atomically.
